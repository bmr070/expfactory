Create the expfactory-agent GitHub App

Open this file in a browser and press the button. GitHub's creation page opens with every permission already set from provision/github-app-manifest.json. Review it, then click Create GitHub App.

Nothing here handles a credential. The button only pre-fills a form.

What it grants

  • contents: write — push branches
  • pull_requests: write — open PRs
  • issues: read — read tickets, never label them
  • metadata: read — mandatory

What it deliberately withholds

administration is absent. An agent that can edit branch protection can unlock its own cage, and every other control in the repo becomes decorative. If you find yourself adding it later, that is the moment to stop.

issues is read-only, not write. The agent must never be able to apply agent-ready — including to a ticket it filed itself. That label is the whole dispatch boundary (invariant 7).

No webhook. The runner polls. Leave webhooks off.

After GitHub creates it

  1. Copy the App ID from the top of the settings page.
  2. Generate a private key, save the .pem somewhere outside this repo.
  3. Click Install App → select only bmr070/expfactory.
  4. After installing, read the Installation ID off the URL: github.com/settings/installations/12345678
  5. Add @expfactory-agent as a collaborator with write, so its PRs are reviewable. Do not add it to .github/CODEOWNERS — it must never be able to approve the red lane.
